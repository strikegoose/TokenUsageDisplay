# Kimi / ARK 登录态过期自愈方案纪要

- **讨论时间**:2026-08-16 11:55–12:35(CST)
- **模型/工具**:Kimi Code CLI(kimi 二进制 arm64),macOS 本机,工作目录 `/Users/newgoose/aihq/apps/TokenUsageDisplay`
- **原文回溯**:`/Users/newgoose/.kimi-code/sessions/wd_tokenusagedisplay_89d05b6d4516/session_e95cddd3-5717-4869-bde0-dfbbfa816924/agents/main/wire.jsonl`(用 Grep 按关键词搜此文件可找回原话)

## 背景

菜单栏 App 中 Kimi 与 ARK 频繁报"登录态已过期":Kimi access token 仅 15 分钟(`expires_in=900`),用户不开 kimi CLI 就过期;ARK 的 volc SSO refresh token 长期不用会死(现场已 9 天),只能浏览器重登。

## 关键事实(从 kimi 二进制逆向确认,日后复用)

- Kimi OAuth 刷新协议:`POST https://auth.kimi.com/api/oauth/token`,form 编码,参数 `client_id=17e5f671-d194-4dfb-9706-5516cb48c098`、`grant_type=refresh_token`、`refresh_token=<RT>`;200 返回 `{access_token, refresh_token(每次轮换), expires_in, ...}`,须写回 `~/.kimi-code/credentials/kimi-code.json`(`expires_at = now + expires_in`)。
- OAuth host 可用环境变量覆盖:`KIMI_CODE_OAUTH_HOST` / `KIMI_OAUTH_HOST`。
- `kimi login` 是 device-code 流程(device_authorization 端点 `{host}/api/oauth/device_authorization`)。
- kimi CLI 持有内存态 token,凭证文件 mtime 只在启动刷新时更新 → App 轮换 RT 后,正在运行的 CLI 会话下次刷新可能 invalid_grant(偶发竞态,重新 `kimi login` 可恢复,可接受)。
- arkcli 侧:`arkcli auth status` 可续 STS(App 已用);`arkcli auth login volc-sso` 浏览器 SSO 是唯一重登途径;凭证在 `~/.arkcli/identities/vc-*/{token,sts}.json`。

## 决策(两层方案,已实施)

1. **Kimi 静默刷新(治本)**:`KimiAuthManager.accessToken()` 在 token 过期时自行刷新并写回轮换凭证;single-flight Task 防并发;4xx 判 rejected 重读文件重试一次(防 CLI 竞态);`KimiProvider` 收到 401 强制刷新重试一次,仍败才抛新的 `ServiceError.reauthRequired`。
2. **「重新登录」按钮(兜底,Kimi/ARK)**:`ServiceManager` 用 `reauthServices: Set<String>` 追踪需重登的服务(识别 `reauthRequired` / `ARKCLIError.authExpired`),经 `DashboardViewModel.reauthServiceIds` 传到卡片;错误行右侧出现「重新登录」按钮,新工具 `ReloginLauncher` 写临时 `.command` 文件用 Terminal 打开执行(`kimi login` / `arkcli auth login volc-sso`,绝对路径)——无需 AppleScript 自动化权限,交互提示对用户可见。

## 验证结果(现场实测)

- 将 credentials 的 `expires_at` 改到过去 →  App 下轮 poll 日志 `[KimiAuth] Access token refreshed`,refresh_token 已轮换写回(尾部 9NFq_Q→OqWxRg),Kimi 四张卡(周配额/5h窗口/加油包余额/月度加油包)全部恢复。
- ARK 按预期报 authExpired → 按钮态生效(UI 肉眼验证留给用户)。
- `swift build -c release` 无警告通过;`./build.sh` 打包;新版 App 已在运行。
